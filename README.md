# Running Example — Godot 2D Platformer

Projeto didático desenvolvido para a disciplina de **Programação para Jogos** da UFC.

Este repositório contém um exemplo simples de jogo de plataforma 2D feito em Godot, com movimentação de personagem, pulo, ataques, animações, inimigos, colisões e reinício de cena.

## Sobre o projeto

O objetivo do projeto é demonstrar, de forma prática, algumas mecânicas básicas de jogos 2D na Godot.

O jogador controla um personagem capaz de andar, pular, rolar e atacar. O cenário possui inimigos com patrulha automática e áreas de dano que reiniciam a cena quando o jogador morre.

## Mecânicas

- Movimentação horizontal
- Pulo
- Rolagem
- Ataque primário e secundário
- Animações do jogador
- Inimigo com patrulha
- Colisões e áreas de dano
- Reinício da cena após morte

## Controles

| Ação | Tecla / Botão |
| --- | --- |
| Mover para direita | D |
| Mover para esquerda | A |
| Pular | W ou Espaço |
| Rolar | Shift |
| Ataque primário | Botão esquerdo do mouse |
| Ataque secundário | Botão direito do mouse |

## Tecnologias

- Godot 4.4
- GDScript
